# Security policy

KLineScan talks to vehicle networks and can change vehicle state. Please do not
open a public issue for a security problem.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/fazyamir/KLineScan/security/advisories/new).
Include a description, affected version, reproduction steps and any relevant
trace (redact VINs, plates and personal data first).

The maintainer will acknowledge the report as soon as practical and coordinate a
fix and disclosure. This is a personal project, so no formal SLA is offered.
